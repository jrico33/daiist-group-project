# Evaluation photos

Photos for `eval/cases.csv`, `eval/reference.csv` and `eval/shifted.csv` go here, named after their row, for example `c29.jpg`.

Rules (the repository is public):

- No people or faces, no readable names or number plates, nothing personal.
- About 1024 pixels wide and under 300 KB each.
- Location switched off in the photo's metadata.
- Your own photos, or Wikimedia Commons (CC0 or CC-BY). Write the source and licence in `REPORT.md`, section Data.
